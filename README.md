# 小猫桌面宠物

默认宠物已改为根据用户参考图制作的透明背景 Q 版角色：黑色长发、深色帽子、棕色外套和红色项链。启动即可使用，无需 API 密钥；双击爱心互动，右键可喂食、跳跃、睡觉/唤醒。此内置版本使用一张角色图配合动画效果，尚未制作独立动作姿势。素材位于 `assets/character-idle.png`。

基于 Electron 的桌面宠物基础版本，支持透明置顶窗口、拖动、待机动画、双击摸摸和右键喂食/退出。

## 用自己的角色图片

在 Windows 上启动后，右键宠物 → **导入角色图片…**。支持 PNG、JPEG、WebP 和 GIF，最大 10 MB。透明 PNG 效果最好；普通图片会保留原有背景。图片只保存在本机应用数据目录，下次打开自动恢复，不会上传到网络。右键可恢复默认小猫。

直接导入的图片使用位移、旋转和表情符号互动，保留原背景。

## 在应用内生成 AI 宠物

右键宠物 → **AI 宠物创作室…**，选择角色参考图片，输入自己的 OpenAI API 密钥，选择 Q 版动漫或像素风，勾选允许上传，然后点击生成。需要能访问 `api.openai.com`，且账号具有 `gpt-image-1` 的调用权限和可用额度。

默认生成待机、开心、吃东西、跳跃、睡觉五张透明 PNG（5 次收费请求）；也可取消互动姿势，仅生成一张（1 次请求）。后续姿势以生成的待机图为参考，帮助保持角色一致，但 AI 输出仍可能有差异。生成后可切换姿势预览，点击 **设为桌面宠物** 才会替换当前形象。双击和右键互动会切换对应姿势；待机图和全部姿势在重启后保留。

生成请求会将参考图片发送到 OpenAI；本地导入无需联网。密钥只在当前创作室会话使用，不保存到磁盘，关闭创作室后需重新输入。生成失败或取消不会替换当前宠物。取消无法保证撤销已处理请求的费用。接口固定使用 OpenAI 官方 HTTPS 地址，没有第三方转发服务。

`npm test` 检查请求参数、多姿势生成、错误处理及取消，使用模拟响应，不会调用收费 API。真实生成需要用户提供密钥，本仓库不包含密钥。

## 本地运行

需要 Node.js 22 或更新版本，以及图形桌面环境。

```sh
npm ci
npm start
```

首次安装且尚无锁文件时使用 `npm install`。静态语法检查：`npm run check`。

Windows、macOS 和 Linux 使用同一套代码。Linux 透明窗口需要桌面合成器；Wayland 下窗口定位与置顶行为受窗口管理器限制。无显示服务的云机器不能直接显示桌面宠物。

当前是源码运行版本，尚未制作 Windows 安装包。内置小猫和本地图片导入无需 API 密钥；AI 生成需要用户自行配置。
